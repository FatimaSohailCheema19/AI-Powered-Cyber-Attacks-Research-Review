# 🛡️ AI-Powered Cyber Attacks — Research Review

A research-based cybersecurity literature review exploring how **Artificial Intelligence, Generative AI, and Large Language Models (LLMs)** are influencing modern cyber attacks.

This project analyzes recent research on AI-assisted phishing, deepfakes, vulnerability exploitation, malicious code generation, spoofing, adaptive attacks, and AI-driven cyber defense.

---

## 📌 Overview

Artificial Intelligence is increasingly becoming a dual-use technology in cybersecurity.

The same AI systems that can support:

- Threat intelligence
- Secure coding
- Anomaly detection
- Incident response
- Vulnerability analysis

can also be misused by attackers to:

- Generate convincing phishing messages
- Automate reconnaissance
- Discover vulnerabilities
- Produce malicious code
- Create deepfake identities
- Support spoofing and social engineering
- Adapt attacks more quickly

This review studies how AI changes the **scale, speed, personalization, and effectiveness** of modern cyber attacks.

---

## 🔍 Research Scope

The review focuses mainly on the malicious and adversarial use of AI in cyber operations.

Defensive AI techniques are discussed where they directly address AI-powered attacks.

The reviewed literature includes research published in **2025–2026** and covers areas such as:

- Generative AI in cybersecurity
- LLM-assisted phishing
- Deepfake-enabled cybercrime
- AI-supported vulnerability exploitation
- UAV jamming and spoofing
- AI-based attack prediction
- Phishing detection using ML and LLMs

## ⚠️ Major AI-Powered Threats

### 🎣 AI-Assisted Phishing

Large Language Models can generate convincing and personalized phishing messages while reducing grammatical errors and improving realism.

---

### 🎭 Deepfake Attacks

AI-generated images, audio, and video can support:

- Identity impersonation
- Social engineering
- Fraud
- Disinformation
- Trust manipulation

---

### 💻 AI-Assisted Vulnerability Exploitation

AI can assist attackers in:

- Discovering vulnerabilities
- Prioritizing weaknesses
- Automating reconnaissance
- Supporting exploit generation
- Accelerating attack workflows

---

### 🤖 Malicious Code Generation

Generative AI may be misused to produce or modify malicious code and lower the technical barrier for certain cyber attacks.

---

### 🧠 Prompt Injection and Model Manipulation

AI systems themselves can become attack targets through:

- Prompt injection
- Data poisoning
- Unsafe model outputs
- Manipulated inputs
- Sensitive information leakage

---

### 📡 UAV Jamming and Spoofing

AI techniques may also be used in cyber-physical attacks involving:

- Navigation spoofing
- Communication interference
- Mission disruption
- Signal manipulation

---

- Finance

## 🔐 Defensive Measures

The reviewed studies recommend several approaches for reducing AI-related cybersecurity risks:

- Human-in-the-loop validation
- Adversarial testing
- Secure AI model development
- Input and output filtering
- Strong access controls
- Data governance
- Continuous monitoring
- Behavioral detection
- Multi-factor authentication
- Explainable AI
- Security awareness training
- Model evaluation and red-teaming

---

## 📊 Key Findings

The literature suggests that AI does not always create entirely new categories of cyber attacks.

Instead, it often strengthens existing attacks by making them:

- Faster
- More scalable
- More personalized
- More convincing
- Easier to automate
- More difficult to detect

The research also shows that AI can significantly support defenders, meaning the future of cybersecurity will likely involve an ongoing AI-driven attacker-versus-defender cycle.
